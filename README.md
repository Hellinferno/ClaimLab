## ⬡ The Problem & The ClaimLab Solution

Traditional generative AI tutors suffer from three critical flaws:
1. **Hallucinated Graphs & Numbers:** Models invent chart trends and arbitrary curves that never came from actual calculations.
2. **Epistemic Ambiguity:** Chatbots blend factual paper claims, ungrounded speculation, and prompt instructions into homogeneous prose.
3. **Superficial Feedback Loops:** Simple chat turns acknowledge student answers without altering subsequent pedagogical strategy.

### ClaimLab's Core Breakthrough
* **100% Measured Visuals:** Every plot, curve, and heatmap is rendered exclusively from retained numerical simulation outputs calculated by a sandboxed float64 runner.
* **Strict Epistemic Partitioning:** All teacher utterances are tagged explicitly with `[Source]`, `[Experiment]`, or `[Background]` grounding badges.
* **Evidence-Based Adaptation:** Student actions advance categorical mastery (`Introduced` &rarr; `Needs Check` &rarr; `Supported with Help` &rarr; `Supported Independently`). Progressing to independent mastery strictly requires completing **two distinct mathematical variants**.

## 🔬 The Three Verified Numerical Laboratories

ClaimLab eliminates hallucinated graphs by running exact numerical recipes:

### Recipe A &bull; Softmax Sensitivity (`softmax_sensitivity_v1`)
Investigates temperature scaling and score distribution sharpening:
$$p_i = \frac{\exp(\alpha \cdot s_i)}{\sum_j \exp(\alpha \cdot s_j)}$$
* **Mathematical Invariants Verified:**
  - $\sum_i p_i \equiv 1.0$ within $| \text{err} | < 10^{-10}$
  - Multiplier $\alpha > 1.0$ strictly increases peak probability and decreases entropy: $H(p_{\text{scaled}}) < H(p_{\text{base}})$
  - Shift invariance: $p(s + c) \equiv p(s)$

### Recipe B &bull; Attention Dimension Scaling (`attention_scaling_v1`)
Simulates dot-product query-key matching across vector dimensions $d_k \in \{8, 32, 128\}$:
$$S = \frac{Q K^T}{\sqrt{d_k}} \quad \text{where } Q, K \sim \mathcal{N}(0, I_{d_k})$$
* **Mathematical Invariants Verified:**
  - Unscaled variance grows linearly with dimension: $\text{Var}(Q K^T) \approx d_k$
  - Scaled variance stabilizes invariant of dimension: $\text{Var}\left(\frac{Q K^T}{\sqrt{d_k}}\right) \approx 1.0$
  - Independent scalar reference validation within $10^{-10}$ tolerance.

### Recipe C &bull; Causal Attention Masking (`causal_masking_v1`)
Enforces autoregressive visibility constraints using lower-triangular masking:
$$M_{ij} = \begin{cases} 0 & \text{if } j \le i \\ -\infty & \text{if } j > i \end{cases} \qquad W = \text{softmax}(S + M)$$
* **Mathematical Invariants Verified:**
  - Future tokens strictly receive zero attention weight: $W_{ij} \equiv 0.0 \; (\forall j > i)$
  - Allowed token positions retain unit row sum: $\sum_{j=1}^i W_{ij} \equiv 1.0$

## ⚡ Interactive Whiteboard & Atomic Patch Engine

The whiteboard operates as a strict state machine governed by immutable revisions:

```typescript
interface BoardPatch {
  schema_version: 1;
  base_board_revision: number;    // Stale revisions immediately rejected
  commands: BoardCommand[];       // Max 20 commands per transaction
}
```

* **Supported Atomic Operations:**
  - `add_object`: Inserts nodes, equations, plot bindings, or annotations.
  - `update_object`: Repositions, re-labels, or updates payloads.
  - `add_connector`: Binds directed relational arrows between concepts.
  - `remove_object`: Deletes an object and **automatically cascades** to remove orphaned connectors.
  - `highlight_objects` / `clear_highlights`: Highlights focus regions during tutor turns.
* **Injection Defense:** All LaTeX and textual content is scanned against forbidden patterns (`<script>`, `javascript:`, `\write`, `\immediate`, `\input`) before committing to the scene graph.

## 🔒 Security & Fencing Invariants

* **Tenant Isolation:** Ephemeral HMAC-SHA256 authenticated cookies (`claimlab_guest`). Requests for resources owned by another guest return an immediate `404 Not Found`.
* **CSRF & Origin Verification:** All state-mutating routes verify the `X-CSRF-Token` header.
* **Idempotency Fingerprinting:** Requests with an `Idempotency-Key` header compute a SHA-256 fingerprint over the request payload. Duplicate calls safely replay cached responses; payload mismatches are rejected with HTTP 409.
* **Complete Data Purge (`DELETE /api/v1/me/data`):**
  - Increments fencing generation numbers to invalidate inflight background jobs.
  - Deletes physical PDF files from storage.
  - Revokes guest credentials immediately; subsequent requests return HTTP 401.

## 🚀 Quickstart & Deployment

### 1. Clone & Setup Workspace
```bash
git clone https://github.com/Hellinferno/ClaimLab.git
cd ClaimLab
```

### 2. Backend Setup
```bash
# Initialize Python 3.12 virtual environment
python -m venv .venv
.\.venv\Scripts\Activate.ps1   # Windows (or source .venv/bin/activate on Linux/macOS)

# Install locked dependencies
pip install -r backend/requirements.txt
pip install -e backend --no-deps

# Run full test suite (21 unit & integration tests)
pytest backend/tests/ -v

# Start FastAPI application
python -m uvicorn claimlab.api:app --host 127.0.0.1 --port 8000 --reload
```

### 3. Frontend Setup
```bash
# Install Node dependencies
npm --prefix frontend install

# Build production bundle
npm --prefix frontend run build

# Start Vite development server
npm --prefix frontend run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.

### 4. Background Async Worker
```bash
python -m claimlab.worker
```
